# Design System - Tamil Food Thaya

The platform follows a **Premium Dutch-Tamil** aesthetic: Minimalism meets rich cultural textures.

## 🎨 Color Palette

| Category | Color | Variable | Description |
| :--- | :--- | :--- | :--- |
| **Primary** | `#800000` | `tamil-maroon` | Sacred maroon, used for CTAs and branding. |
| **Accent** | `#FFD700` | `tamil-gold` | Premium gold, used for highlights and headers. |
| **Background** | `#F8F9FA` | `off-white` | clean Dutch minimalist background. |
| **Text** | `#2D3436` | `tamil-charcoal` | High contrast charcoal for readability. |

## Typography
- **Primary Font**: `Poppins` - Modern sans-serif, used for headings and branding.
- **Secondary Font**: `Inter` - Standardized for high legibility in Dutch interfaces.

## UI Principles
1. **Dutch Minimalism**: Wide margins, clear hierarchy, no clutter.
2. **Tamil Accents**: Subtle motifs, vibrant food photography, gold highlights.
3. **Mobile First**: Fixed WhatsApp button, bottom cart drawer on mobile.
4. **Visual Trust**: Clear price labels, Stripe logos, and KvK info in footer.

## Components
- **Button**: All caps, tracking-wide. Maroon (Primary), Gold (Secondary), Outline (Nav).
- **Cards**: Soft shadows (`shadow-md`), slight border (`border-gray-100`), white background.
- **Header**: Transparent on hero, solid/shadow on scroll.
