# UI Pro Max Skill

This skill enforces the highest standards of modern web design and UI/UX development.

## Core Directives

1. **Stunning First Impression**: The user must be wowed. Use vibrant colors, sleek dark modes, glassmorphism, and dynamic animations.
2. **Premium Aesthetics**: Avoid generic colors (plain red, blue, green). Use curated palettes, modern typography (Inter, Roboto, Outfit), and smooth gradients.
3. **Dynamic & Alive**: Interfaces should react to user interaction. Use hover effects, subtle micro-animations, and smooth transitions.
4. **No Placeholders**: Always generate functional mockups or use the `generate_image` tool to create real visual assets for demonstrations.
5. **Polished Experience**: Never deliver a "minimum viable product" aesthetic. Every component must look like a state-of-the-art SaaS or premium product.

## Implementation Steps

When tasked with a UI feature:
1. **Plan & Systematize**: Establish design tokens (colors, fonts, spacing) in your CSS (e.g., `index.css`) before building ad-hoc components.
2. **Build Components**: Ensure all buttons, cards, and inputs use the established design system. Add interactive states (hover/focus/active) to everything clickable.
3. **Assemble**: Construct the layout ensuring responsiveness and proper alignment.
4. **Polish**: Review the contrast, spacing, and micro-interactions. Ensure the UI feels responsive and premium.
